Enhancement Two

This application originally had two list, one for monkey and one for dog to save them and refer to them. This can be used to search for the animals and print them, as well as find one to reserve. This enhancement displays my ability in algorithms and data structure because I will be optimizing the search making it quicker and optimizing the security of the application. Another change that I made in this enhancement was incorporating a login to make sure that the application is secure. I have met the course outcomes that I planned to meet with this enhancement because I was able to convert the two list and use one list. This helps optimize the performance of the application when searching and other options with the list. I was also able to add the login feature which will help strengthen the security of the application. I learned how to incorporate a list that has two different types in one and still be able to sort it and get specific items from it. I didn’t have many issues with this conversion, I just broke it up function by function making them all work with the one list rather than trying to change it all at once.

Enhancement Three

This enhancement displays my ability in my ability to create a database. The way that I the original artifact better in this enhancement was converting the saved animals to be housed in a database rather than in a list on the program itself. This database will be on a local server but will seed the original animals when the program is run for the first time. Originally in the plan I had talked about making it a full stack application, but I decided to pivot to just adding the database to the single terminal program. I thought that this would help amplify my overall knowledge of database rather than working on the full stack application as well. I learned how to create a database to an already completed application, this was a bit different then I was use to because I usually develop it with the application rather than after. It was a bit complicated to make everything work correctly and still be able to seed the application with the animals that were in the list. I also saved the username and password in an .env doc to keep it separate from the actual program itself.
